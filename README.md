# Typing Speed Test

A typing speed test application built with React.

![image alt](https://raw.githubusercontent.com/MeharYG-dev/typing-speed-test-react/cd31016b6b9e3d318a157e07a03f768015f79853/Typing_Speed.png)

## Features

- Random typing passages
- 60-second timer
- Words Per Minute (WPM) calculation
- Accuracy calculation
- Correct and incorrect character highlighting
- Restart functionality

## Technologies Used

- React
- JavaScript
- CSS
- Vite
